# Lyla Rose Games

A little collection of unicorn games, hosted on GitHub Pages.

## Games

| Game | Folder |
| --- | --- |
| Sparklehoof's Maze | `games/unicorn-maze/` |

## Adding a new game

1. Make a new folder inside `games/`, for example `games/rainbow-catch/`.
2. Put the game in that folder as `index.html`.
3. Open the main `index.html` and add one line to the `games` list near the bottom (copy the example line).
4. Commit and push. GitHub Pages updates in a minute or two.
